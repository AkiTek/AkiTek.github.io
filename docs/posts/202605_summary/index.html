“Note"での発信強化 Link to heading

年初の抱負にかかげていた「Note」での発信を再開した.

さて, Noteを始める理由は3つあった. １つ目は, 日々の学びを 「発信」するというアウトプットの観点 での強化のため ２つ目は, お金の勉強をしたいという動機から,,,いわゆる「コンテンツ販売型」ビジネスを狙うこと

その過程で, いくつかライディングの練習もできた. 発信にあたり「感情設計」「ストーリー性」といった, 「論理的な説明」の世界にいた人間からすれば馴染みのないライティング術にあたふたした.

たしかに, 「情報発信」よりも「共感型」記事のほうが, 今の時代は良いのかもしれない.

同時に, 「自己ブランディング」の重要性 もみえてきた. 「自分はどのような人間で, どのような人に向けて, どんな悩みを解決してあげられるのか」…

100万人のフォロワーよりも, 一人のファンをつくるための仕組み をしっかり学びたいとNoteで活動しながら感じた.

「研究者」が, 「ユーザーとの接触頻度」を増やす仕組み…とは一体なんだろうか？

人工知能学会の準備 Link to heading

きたる人工知能学会でのオーガナイズドセッション/企画セッションの最終準備を進めた. 学会でのセッション開催というのは人生初で, 緊張と共にわくわく感がここ数日落ち着かない.

昨年の11月ごろから活動をはじめ, 半年以上の準備を経てきた. アカデミックのこの場から, 「GeoAI」というテーマを盛り上げていきたい,,, そういう思いで始めた.

「最初からうまくいくわけない」…とは思うが, なんとか**「歴史に活動の痕跡」を残したい.** それだけでも十分だ.

健康増進トレーニング Link to heading

脳機能のリハビリのため, 夜ランニングを週３程度で継続.

暑くなってきたこともあり, ランニング中の汗の量が膨大に.

運動強度は同じレベルで, ただ移動距離と走るペースが上がってきたと思う. ノルマとして, ５kmを30分以内…

ここいらをベースラインに, 継続的に運動をしていきたい.

あとは, 屋内での脚トレが止まっているので再開する習慣ができればいいのだが… やれやれ
