“Threads"での発信強化 Link to heading

Noteでの記事を使って、Noteへの集客を狙いに、Threadsのアカウント運用を開始。 すでに、Note✖️Threadsというのはトレンドになっているようで、いろいろなつぶやきが存在した。

少なくとも思ったのでは、SNSマーケティングという戦い方の「基本の型」である、

営業しない。 誘導しない。 批判しない。

「共感」や「感動」、ちょっと「ツッコミたくなる」ような投稿が良いらしい（Threadsのアルゴリズム的にも）

Threadsでの投稿については、後述Claudeで自動投稿ツールを作った。 その投稿内容の大元は、Note記事である。

Noteの記事が、私個人の語録集であるとみなし、”それらしい”投稿を自動で代替してくれる。とても便利だ。 ついで、各投稿へのインプレッションを分析し、また、Threads全体のマナーや書き方のテクニックを自動で反映する仕組みに。

おかげさまで、フォロワーが増えつつある。 しばらく様子を見よう。

人工知能学会の運営・参加 Link to heading

人工知能学会のOS/KSの運営に参加。 初テーマのセッションにもかかわらず、両方とも１００名を超える参加者に恵まれた。

企画セッションのほうでは、多少のトラブルが発生したが、 全体としては良好な結果で終わった。

運営サイドでは、「認知度」の向上、名刺交換が目立った。

やはり、「所定テーマ」のセッションを立ち上げること自体、とても大事なトライであると実感した。

継続してコミュニティを維持・強化していきたい。

Claude活用 Link to heading

今月の中旬からはClaudeの活用まみれであった。 いろいろなツールが、バイブコーディングで作成できることに驚きを隠せない。

業務でも、Claudeを使った研究支援も行っている。

これまでコードの打ち込みや、プログラミング言語の勉強、といった研究外の作業が一気に効率化された。

Claudeを当たり前とした働き方に今後なっていくだろう。

その分、「自由時間」が増えるはずである。そうした時間は、AIに代替できないもの たとえば、「睡眠」や「健康」「運動」、「趣味」といった「仕事」以外のものに当てていきたい。

Claudeのおかげで、いろいろなことが効率よくできるようになったが、 結果として、仕事を増やしたり、意思決定の負担を増やすような真似はしないようにしよう。

いまはまだ対話型AI導入の過渡期。　空いた時間は、自分の健康のために使おうと思う。
