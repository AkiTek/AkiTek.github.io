“ジム利用開始” Link to heading

7月中ばから、Anytimeジムに通うことにした。 日に日に暑くなっていくなか、夜中の長距離ランニングの疲労も高まっていることに課題を感じていた。 他にも、雨天の場合にランニングできないこと、ランニング以外の筋トレができていないことも気になっていた。

その点、ジムであれば、天候を気にせず、また、筋トレ用の環境が整っている。 Anytimeのキャンペーンのお得感、24時間営業、どこのAnytimeジムを利用しても良いという利便性…

人生はじめてのジム通いをはじめた.

腹筋 トレッドミル 背中 ブルガリアンスクワット…

ダイエットをはじめ、筋トレ(ウェイトトレーニング)のほうが、血行促進に効果あるようで、 ランニングに集中していたが、筋トレをしっかり組み込んでいくことにした。

裁量労働という、働き方のフレキシビリティーを活かして、適宜ジムトレーニングを導入していく。

“Threads"での発信進捗 Link to heading

発信自動化を起こしてから、ついにフォロワー100名を超えることができた。

いまは、いろいろと忙しさもあり、記事を更新できていないけれど、 過去のNote記事の閲覧数も増えている。

9,10月にかけて、またNote記事の数を増やしたり、有料記事の執筆を検討していきたい。

あまり、意識をSNSに向けすぎないことが、メンタル的にも重要だ。

人工知能学会の運営・参加 Link to heading

人工知能学会のOS/KSの運営の参加報告を、学会に提出。

開催から一ヶ月、再度オーガナイザー間で議論し、来年度もOSに提案することで合意。 また、研究会の発足についても、急ぎ協議を進めていきたいところ。

学会という空気感がすごく良いなと感じる。

来年度は、出島（長崎）で行うようだ。
